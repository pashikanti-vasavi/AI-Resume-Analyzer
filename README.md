# AI Resume Analyzer

An AI-powered resume analysis tool built using Python and Streamlit.

## Features

- Upload resume in PDF format
- Extract resume text
- Compare resume with a job description
- Calculate overall resume match percentage
- Identify matched skills
- Identify missing skills
- Calculate resume strength
- Provide personalized improvement suggestions

## Technologies Used

- Python
- Streamlit
- PyPDF2

## Live Demo

https://pashikanti-vasavi-ai-resume-analyzer-app-weejuv.streamlit.app/

## Project Purpose

This project helps job seekers understand how well their resume matches a specific job description and identify skills they can improve.
